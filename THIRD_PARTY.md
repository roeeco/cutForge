# Third-party code

No source code has been copied from the reference repositories (MocknSlice, Foldform, Die Cut Studio, Extrudo, SketchForge-3D, layerling). The SVG and DXF writers, joint geometry, outline booleans, through-cuts and packer in this repository are original.

**Adapted from Foldform** ([roeeco/foldform](https://github.com/roeeco/foldform), the owner's code; the commit read on 2026-11-07 was not recorded in `CORRUGATED_JOINTS.md`): design rules and constants only, re-implemented here — no code was copied. From `app/lib/template-kernel.ts` (fold-over walls, lines ~467–610): the rim strip of 2t + score allowance with a crease at each edge, the liner of h − t, lock tabs as trapezoids tapered by 18% of their width, the tab width clamp and the two-tabs-at-0.3L/0.7L rule, and the validation rules (wall ≤ 2t, lock depth > 0.6h, edge too narrow, c < 0.75t, hem > 0.45h). From `dieline.ts` (~line 416): the score allowance `max(0.3, round(1.25t/0.05)·0.05)`, which equals CutForge's `foldAllowance`. Used in `src/model/foldover.ts` and `src/model/validate.ts`. Differences: slots use CutForge's clearance-once rule (foldform adds 2c), slots are set back for a minimum web, and liners give way at corners.

When code is copied or adapted, record it here with repository, commit and license (and keep the MIT notices for Die Cut Studio and Extrudo `packages/io`). Extrudo's GPL code and the AGPL code of SketchForge-3D and layerling (henmedia/layerling) are behaviour references only and must not be copied or translated; so are the GPL unfolders named in `MODEL_MODES_RESEARCH.md` (the Blender add-on, PolyZamboni). Papercraft (rodrigorc/papercraft, GPL-3.0-or-later) is a behaviour reference only too: `src/model/foldRules.ts` and Make's check of the laid net (`reassemble.ts` `netProblems`) take its ideas (one layout for the net, folds near flat kept but not scored), written fresh. Milestone 119's unfolder (`tests/spike/unfoldSpike.ts`) follows that file's §3 pipeline as a description, written fresh. boxes.py (florianfesti/boxes, GPL-3.0) is a behaviour reference only too, for the board-built presets of `BOXES_PRESETS_PLAN.md` (milestones 161–170): its constructions, proportions and default sizes are read, and each preset is written fresh against CutForge's own ops; no code is copied or translated (its gear and pulley maths included: the involute outline is written from the standard formulas). Each preset that took a construction from it names its generator here when it is built. Built (milestones 161–169, `src/templates/structures/board*.ts`, the stand's angled slots on 4 mm board and the plywood drawer): the open-front box (openbox, notesholder), pen holder (penholderbox), scoop tray (smallpartstray), bird house (birdhouse), bookend (halfbox), sliding-lid box (slidinglidbox), laptop stand (laptopstand), grid insert (trayinsert), shelf (storageshelf, wallrack), bottle rack (bottlestack, winerack), desk sign (desksign), slanted shelf (displayshelf), plywood drawer (slidingdrawer). Milestone 171 (`BOXES_PLYWOOD_PLAN.md`): the half box's triangular sides, keyholes and clamp holes (halfbox), the box's closed top, lid rim and grips (universalbox, two_piece, closedbox). Milestone 172: the shelf's rack (storagerack), the slanted shelf's lips, spaces, back and sloped sides (displayshelf), the bin rack (bintray), the wall rack (wallrack). Milestone 180: the chamfered box (angledbox), the coffin box (coffin), the tetromino box (tetris), the star box (regularstarbox, read; its star built as a footprint instead), and for the taper spike regularbox and fatballdispenser.

Python test helpers (not shipped): ezdxf (MIT), svgpathtools (MIT).

## Stickers
Quick build's stickers (`src/easy/stickers.ts`: star, heart, house, lightning, moon, flower, smile, tree) were drawn for CutForge as simple closed outlines generated in code; no icon set was copied. They are released with the project under its own license (and may be used as public domain, CC0 1.0). Nothing is fetched at run time.
